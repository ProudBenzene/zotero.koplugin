# Zotero for KOReader：简体中文使用指南

此插件可在 [KOReader](https://github.com/koreader/koreader) 中浏览 Zotero 个人文献库，下载并阅读 PDF/EPUB 附件，查看 Zotero 云端 PDF 批注。插件仍处于测试阶段；[英文说明与开发测试](README.md)保留技术细节。

## 安装与账户配置

1. 将插件源码文件复制到 `<KOReader>/plugins/zotero.koplugin`。升级时也要复制新增的 `i18n.lua`。
2. 在 [Zotero API 密钥设置](https://www.zotero.org/settings/keys)中创建专用 API 密钥，允许读取个人文献库；通过 Zotero File Storage 下载文件时，还需允许读取文件。记下数字用户 ID 和密钥。
3. 启动或重启 KOReader，在顶部菜单的搜索页签（放大镜图标）中打开 **Zotero → 设置 → 配置 Zotero 账户**，填写用户 ID 和 API 密钥，点按 **保存**。
4. 返回 **Zotero → 同步**，等待同步完成，再打开 **浏览文献库**。

KOReader 界面语言为简体中文（`zh_CN` 或 `zh_Hans`）时，插件显示简体中文。英文和其他语言使用 KOReader 的 gettext 回退。文献题名、作者、分类名称、文件名和批注正文保持原样；`All Items`、`Zotero Annotation`、`Zotero key`、DOI、PDF/EPUB 和协议字段保留英文。

### WebDAV 配置

Zotero 元数据始终通过 Zotero Web API 同步；WebDAV 用于下载已存储的附件。

在 **Zotero → 设置** 中启用 **WebDAV 存储**，打开 **配置 WebDAV 账户**，填写地址、用户名和密码。地址应指向名为 `zotero` 的目录，例如：

```text
https://your-instance.tld/remote.php/dav/files/your-username/zotero
```

使用 Zotero 文件同步所用的同一账户；服务器支持时可使用应用专用密码。配置后点按 **测试 WebDAV 连接**，成功时显示“WebDAV 连接正常。”。此插件支持 Basic 认证和 HTTPS，不支持仅提供 Digest 认证的服务器。设备需有支持 `-p` 参数的 `unzip` 命令。

插件兼容当前 ZIP 文件名和旧版 `%ZB64` 文件名，并按 Zotero 附件元数据校验解压后的文件。它不上传文件，也不更新 WebDAV `.prop` 元数据。Zotero 端配置方法见 [Zotero 同步说明](https://www.zotero.org/support/sync)。

### 手动配置

也可直接编辑 `<KOReader 数据目录>/zotero/meta.lua`，数据目录的位置因设备和平台而异：

```lua
return {
    ["api_key"] = "", -- API 密钥
    ["user_id"] = "", -- 数字用户 ID
    ["webdav_enabled"] = false,
    ["webdav_url"] = "", -- 指向 WebDAV 的 zotero 目录
    ["webdav_user"] = "",
    ["webdav_password"] = "",
}
```

## 浏览、搜索与阅读

**浏览文献库** 从顶层分类开始。打开分类后，显示它的直接子分类和附件；返回时恢复上一层。再次从主菜单打开文献库，会回到顶层。

**All Items** 显示当前文献库中可阅读的 PDF/EPUB 附件。普通书目条目为附件提供题名和作者信息，不作为单独的可阅读项。因此，同步结果有“文献库条目”，而此处仍可能显示“暂无可阅读附件”。“文献库条目”统计包含书目、附件、笔记和批注等全部条目，不能当作文献篇数。

点按放大镜可按题名、作者信息或 DOI 搜索附件。搜索未命中时显示“未找到匹配的附件”；空分类显示“暂无分类或可阅读附件”；空附件子列表显示“暂无附件”。

同一书目条目有多个附件时，列表先显示文献及附件数量，点按后再选择附件。仅有一个附件时可直接打开。不同 Zotero 书目条目即使题名相同，也保持独立。

长按附件可查看完整文献题名、附件题名、文件名、格式、下载状态、本地大小、文件修改时间（有记录时）、DOI 和 `Zotero key`，并点按 **打开**。同名附件使用编号区分。可在 Zotero 中为附件起“正文”“补充材料”或版本名称，方便选择。

- **已下载**：本地非空文件及下载记录通过当前附件元数据检查，可复用。
- **待更新**：本地文件存在，但不符合当前附件元数据，需要重新下载。
- 仅显示 **PDF/EPUB** 格式：没有可用的本地副本。

状态显示不请求网络，也不对整份 PDF 重算校验和。下载或删除后，重新显示列表即可更新状态。

## 同步与进度

**同步** 更新文献库元数据，并刷新已下载 PDF 的批注。同步成功后分别显示文献库条目、分类、可阅读附件和批注缓存统计。

**维护 → 重新同步整个文献库** 强制全量重建文献库元数据，成功后强制重新获取当前账户所有已下载 PDF 的批注，即使缓存版本未变化也重新获取。该操作覆盖整个文献库，不限于当前分类。**维护 → 重新获取已下载 PDF 的批注** 先执行常规文献库同步，再执行相同的强制批注刷新。两者均不重新下载 PDF；批注更新在下次打开 PDF 时生效。

**维护 → 删除所有本机下载的文献** 扫描本机所有账户的插件存储，包含 PDF、EPUB、待更新副本和可识别的改名或云端已删除附件。先显示可滚动的待删除预览，逐项列出完整本地路径；当前账户有本地元数据时显示文献题名及附件名称，其他情况以文件名显示。预览也显示数量、文件大小、待清理记录，以及会跳过或保留的文件。取消或关闭预览不删除文件；点击预览中的删除按钮后才分批删除，并清理这些文件的本地批注、书签、阅读进度、缓存、最近阅读和阅读收藏。账户设置、文献库元数据及 Zotero/WebDAV 云端数据保留；清理无需联网或有效的 API 密钥。

正在阅读的文档及与它共用阅读数据的下载会跳过。无法确认归属的旧文件、额外放入的文件和符号链接会保留，结果列出位置，不会误报全部清空。删除前重新核对预览文件的路径和内容，真正变化的文件会跳过；扫描与内容核对分批调度，大文件处理期间界面仍能更新。批量删除前会保存清理记录，文件删除后附属数据清理失败时，再次执行此菜单即可继续清理。旧版共享目录中无法识别的文件仍需单独处理。

同步进度显示账户检查、获取条目、获取分类、处理删除和保存等阶段。Zotero 提供总数时，会显示当前查询阶段的数量和百分比；它不是整次同步的总进度。增量同步也按当前查询计数。文献库发生变化并触发重试时，计数会重新开始。

下载进度显示实际接收的字节数，以及解压、校验、保存等阶段。WebDAV 显示接收的 ZIP 字节数。下载过程中不显示百分比或预计完成时间；重定向后，接收计数从新响应开始。

进度框最多每两秒刷新一次，短操作可能直接完成。等待服务器时，最近一次文字会保留到收到新数据或请求超时。同步结果保持显示，等待手动关闭。

元数据分页遇到临时网络错误时，最多尝试三次；短文件响应有可靠校验标识时，可尝试续传。损坏的 WebDAV ZIP 会重新下载一次。失败时保留先前可用的缓存。错误说明会显示失败阶段、接口分页页码或已接收字节数；外部系统诊断作为技术细节保留。

## PDF 批注与本地数据

插件单向导入 Zotero PDF 高亮、下划线、区域批注及颜色、文字和评论，支持云端修改与删除。区域批注显示边框，点按可查看评论。

单独更新一篇 PDF：**浏览文献库 → 长按附件 → 更新批注**。更新后关闭并重新打开 PDF，使缓存生效。第一次通过插件打开时会获取缺失的批注缓存；之后从插件、最近阅读或文件管理器打开可离线使用缓存。仅重新打开 PDF，不会自动获取云端修改。

`Zotero Annotation` 导入项在 KOReader 中只读，可查看、复制、查词和跳转。修改请在 Zotero 中进行，然后同步并重新打开 PDF。独立本地批注仍可创建、编辑和删除，并保存在 KOReader 文档设置中；书签与阅读进度保留。混合批量操作会跳过只读 Zotero 批注，并报告数量。

对于当前账户管理的 Zotero PDF，插件阻止向 PDF 原文件写入批注、批量写入及内嵌批注导入。本地批注不会改写下载的 PDF。普通 PDF、EPUB 和其他账户的文件保持原生行为。插件不上传任何批注。

**浏览文献库 → 长按 PDF/EPUB → 删除本地文件** 会在确认后删除本地文献、批注缓存及本地批注、书签和阅读进度；先关闭正在阅读的文献。Zotero 云端条目与数据保留，之后可以重新下载。

当前目标设备与版本为 **Kindle Oasis 3 / 官方 KOReader v2026.07.2**，支持标准 PDF 页面。文字重排会隐藏导入的批注覆盖层。EPUB 批注、便笺、手写批注、特殊 CropBox 和 PDF 自身页面旋转尚不支持。实际设备验证状态见[批注同步说明与验证记录](docs/annotation-sync.md)。

## 缓存与升级

从旧版升级后先运行一次 **同步**。插件完整重建元数据，之后使用增量同步。元数据和库版本保存在 `zotero/library.json`；每个附件使用独立目录 `zotero/storage/<userID>/<attachmentKey>/`。

旧 `items.json`、`collections.json`、已下载文档及其 KOReader 附属数据会保留。旧版共享目录不能可靠识别附件，新版首次打开会重新下载并校验。旧路径的阅读进度不会自动迁移到新副本。完整重同步成功前，上一份可用元数据仍然保留。

更改用户 ID 或 API 密钥后，插件会为当前账户重新完整同步。插件仅支持个人文献库及 Zotero 存储的 PDF/EPUB 附件（`imported_file`、`imported_url`），不支持链接文件、链接网址、群组文献库、本地 API 或批注上传。

元数据缓存只保留浏览、搜索和下载所需字段，批注使用独立缓存；Zotero 云端内容不变。现有大缓存会在首次加载时逐条转换。首次冷启动浏览会先显示加载提示。

WebDAV 解压失败时，最近一次诊断保存在 `zotero/download-error.log`，失败 ZIP 保存在 `zotero/.zotero-failed-download.zip`；重试成功后也会保留这份记录，之后的解压失败会覆盖它们。

API 协议与检查记录见 [Zotero API 审计](docs/zotero-api-audit.md)。开发测试命令见[英文 README](README.md#development-tests)。
