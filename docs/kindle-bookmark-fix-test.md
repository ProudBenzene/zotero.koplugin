源码基线：`31b5441b46917fca8adfb89acb0ae65198206876`，加上当前 `annotations.lua` 中的书签与无关本地高亮归属修复。包内 `RELEASE.json` 记录逐文件 SHA-256。

## 本版修复与边界

修复查看云端高亮的“…”菜单后，残留选区导致新建本地书签或无关本地高亮误带云端来源标记、重开后被替换的问题。尚未丢失、但已被旧适配器错误标记的书签也会保留；已经删除的书签不会自动恢复。

本版包含当前仓库的单向批注同步、区域批注、单文件更新、本地文件删除及 v2026.07.2 加载兼容功能。后续云端导入项只读、受管 PDF 强制禁止写入等限制尚未实施，见 [实施计划](annotation-readonly-plan.md)。

源码修复已通过 155 项离线回归与 29 项官方 KOReader v2026.07.2 原生模块接口检查。打包时另对解包后的运行源码执行该原生模块检查，并核对包内文件与本次源码一致。检查使用 PDF 几何、绘制及网络替身，不代表 Kindle 实机验收已完成。

## 安装

1. 完全退出 KOReader，然后连接 Kindle。
2. 解压 ZIP，将顶层 `zotero.koplugin` 文件夹内的文件复制并覆盖到 `<KOReader 安装目录>/plugins/zotero.koplugin/`。安装后应直接存在 `plugins/zotero.koplugin/main.lua`，不要多嵌套一层文件夹。
3. 安全弹出 Kindle，再启动 KOReader。无需重设账号或清空数据；本修复不要求重新同步、重新下载或删除文档设置。

安装包只含插件代码、许可证和说明，不含账号配置、缓存、下载文件或测试工具。原有 `<KOReader data directory>/zotero/` 保存账号和数据，不是本次覆盖目录。

## 优先测试

用已经能正常显示 Zotero 云批注的 PDF，记录测试前的书签与阅读位置。

1. 点按一个云端高亮，打开详情中的“…”菜单，然后关闭菜单。
2. 不再长按选择新文字，直接在当前页新增书签。这一步验证残留云选区不会污染书签。
3. 退出当前文档并重新打开，确认新书签和原有书签仍存在，阅读进度能恢复，云端高亮仍显示。
4. 再次查看并关闭云高亮的“…”菜单，然后选择另一段文字新增本地高亮和评论。重开后确认本地高亮与评论仍在。
5. 对有跨页高亮和区域批注的文档，检查跨页点击、区域边框与评论查看正常。
6. 在 Zotero 修改一条云批注，执行 Synchronize 或 Browse 长按该附件 → 更新批注，再关闭并重开 PDF。确认云端变化生效，上述本地书签、高亮、评论和进度仍保留。

本版对云导入项的本地编辑仍按原约定在重开时恢复缓存版本；这不属于本次书签修复的验收失败。
