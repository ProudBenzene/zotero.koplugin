# Kindle 实机测试：Zotero 批注只读版本

当前安装包：`dist/zotero.koplugin-readonly-color-2026-10-10.zip`，也可直接复制 `dist/zotero.koplugin/` 文件夹。相邻 `.sha256` 文件记录安装包校验值，包内 `RELEASE.json` 记录源码基线及逐文件 SHA-256。阅读框保持 KOReader 普通批注弹窗的尺寸：宽为屏幕短边的 80%，高为长边的 40%，长内容在框内滚动。标题附带颜色文字，例如 `Zotero Annotation · 蓝`；自定义颜色显示原始色值。正文末尾不再附加修改提示。当前页直接点按批注时隐藏跳转按钮；从列表或查看其他页的批注时显示“转到批注”。

`dist/zotero-1.koplugin/` 是旧副本，没有 `annotationpolicy.lua`，不包含只读限制。2026-10-10 已确认误装该副本会继续显示旧版编辑入口；无需因此删除已下载论文或阅读数据。

## 安装

完全退出 KOReader 后连接 Kindle，将 ZIP 中的 `zotero.koplugin` 文件夹覆盖到 `<KOReader>/plugins/`。确认 `plugins/zotero.koplugin/main.lua` 与 `annotationpolicy.lua` 直接存在，安全弹出后启动 KOReader。无需清空缓存、文档设置或重新下载。

如果此前安装目录名为 `plugins/zotero-1.koplugin/`，将该旧插件目录移到 `plugins/` 外备份，再安装新版 `zotero.koplugin/`，避免同时加载两份 Zotero 插件。重启后直接从最近阅读或主页打开已有受管 PDF，点按一个确定从 Zotero 导入的批注，应显示标题 `Zotero Annotation` 及对应颜色；独立本地批注仍可编辑。

## 验收

测试前保留一份受管 PDF 的 MD5，以及已有本地高亮、书签和阅读位置。测试结束、完全退出 KOReader 后，再连接设备核对同一 PDF 的 MD5。

1. 点按不同颜色的云端高亮、评论或区域，确认标题为 `Zotero Annotation` 及对应的颜色文字，紫色与品红可区分，自定义色显示原始色值，正文末尾没有修改提示；阅读框应接近 KOReader 普通批注弹窗大小，长内容可在框内滚动。当前页点按入口不应显示跳转按钮；从批注列表或切换到其他页的批注详情时，使用“转到批注”应跳到所在页。查看文字与评论、复制和查词仍可用。详情、更多菜单及批注列表不能编辑或删除云端项。
2. 在高亮设置中尝试打开 PDF 写入、批量写入或删除 PDF 内高亮，确认写入设置被禁用。从批注列表尝试导入内嵌批注，确认显示保护说明，既不改写 PDF，也不生成本地导入项。
3. 创建、编辑、扩展和删除独立本地高亮与评论，添加书签并推进阅读位置；关闭、重开后，未删除的本地项、书签和进度仍在。
4. 将当前样式和颜色应用到全部高亮，确认只改变本地高亮，并显示跳过的 Zotero 项数量。混合选中云端与本地条目，分别执行删除评论及删除条目，确认云端内容和列表行保留，本地操作正常。
5. 查看云高亮的“…”菜单后关闭，再新增书签和另一段本地高亮；重开确认来源没有混淆。检查跨页高亮、区域边框、缩放、裁边和重排切换。
6. 在 Zotero 增改删批注，执行 Synchronize 或 Browse 长按附件 → 更新批注，再重开 PDF。确认云端变化生效，本地批注、书签和进度保留。断网或缓存失败时旧结果保留，PDF 写入保护仍有效。
7. 从 Browse、最近阅读和文件管理器重开同一受管 PDF，确认边界一致；普通 PDF 和 EPUB 保持原有行为。
8. 完全退出 KOReader 后核对受管 PDF 的 MD5，应与测试前一致。

代码检查通过不等于设备验收完成。反馈时记录 KOReader 版本、具体操作、重开前后结果及错误日志。
