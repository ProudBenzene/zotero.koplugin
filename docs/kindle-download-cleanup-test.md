本功能按所有账户清理插件已下载的 PDF/EPUB，也会清理对应的本地批注、书签和阅读进度；Zotero/WebDAV 云端数据、账户配置与主库元数据保留。使用可重新下载的文献进行确认删除验收。

1. 准备若干 PDF 与 EPUB，包含其他账户遗留下载和一份有本地批注、书签及阅读进度的文献。断网后点击“Zotero → 维护 → 删除所有本机下载的文献”。
2. 滚动“待删除文献预览”，核对所有文件的完整路径。当前账户元数据可用时显示文献及附件题名，其他条目用文件名显示。文件名、格式、账户与附件 key 不再单独列出，仍可从路径查看。数量较多时核对末尾条目；未知文件单独列为保留。
3. 分别测试“取消”、标题栏关闭与返回：文献、本地批注、书签及进度保持，随后能正常同步、下载或重新打开预览。
4. 打开一份受管 PDF 或 EPUB 后再次进入此菜单：预览标明该文件正在阅读，确认后它及阅读数据保持，其他可识别下载删除。关闭文献后再次清理，应能处理此前跳过的文件。
5. 确认删除后核对清理结果和文件列表：本地副本与对应阅读数据已删除，未知文件保持；文献库条目仍可浏览，账户与云端文件保持。恢复网络后重新下载当前账户附件，应能重新获取 PDF 批注。
6. 如出现附属数据清理失败，结果应列出路径和原因；再次执行时预览标明“文献文件已删除，仅清理残留的本地数据”。完成重试后不再列出该任务。
